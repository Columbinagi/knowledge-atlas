## 005. 图鉴总览

- id: `start-here`
- 主题: `t0`
- 英文名: Overview

### 你可能会说

> 这份图鉴是怎么组织的？一个主题里该放几张卡？

### 是什么

这份示例图鉴按「总览 → 系统 → 部件」组织：三个主题各管一段，每个主题下是一条条术语卡片——这一条说明它怎么组织、每个主题讲什么、示例包覆盖到哪。

### 详解

- 三个主题。图鉴总览负责「这份图鉴怎么用」；三电系统总览负责「一套动力系统怎么分账」；电驱与电机负责「部件是怎么做出来的」。
- 每条卡片的字段顺序是固定的：你可能会说 → 是什么 → 详解 → 图解与一句话 → 正文分点 → 使用场景 → 容易混淆 → 选择题 → 告诉 AI → 接下来学什么 → 来源。留空的字段不渲染。
- 示例包只放三张卡，每种形态各一张：纯文字卡（三电系统总览）、图解卡（本卡）、带状态机的操作演示卡（多合一电驱）。

### 一句话

三个主题、三张卡：一张讲怎么用，一张只有文字，一张带可操作演示——模板能渲染的三种形态都在这里。

### 演示注解

主题按「总览 → 系统 → 部件」排列，不代表重要性排序。

### 正文分点

#### 三个主题分别讲什么

图鉴总览——这份图鉴怎么组织、卡片有哪些字段、示例包覆盖到哪。三电系统总览——动力电池、电驱、电控三套系统怎么分工，属于「一套系统」的层面。电驱与电机——电驱总成由哪几件组成、集成度怎么往上加，属于「部件」的层面。

#### 现在覆盖到哪了

三个主题各一张卡：图鉴总览 1 张、三电系统总览 1 张、电驱与电机 1 张。示例包不追求覆盖量，只保证每种卡片形态都有一张可跑的样板。

### 容易混淆

- vs **主题导言**：主题下那条说明性词条（不是技术词条），说明这块讲什么。本卡就是图鉴总览主题的导言。
- vs **先知道**：卡片顶部的胶囊，列出读这一条之前需要会的概念。带链接的表示本图鉴里已有对应词条。
- vs **接下来学什么**：卡片末尾给出的下一步去向，按主题顺序往下的那一条。

### 选择题

这份示例图鉴的三个主题按什么顺序排列？

- A. 按技术难度从易到难
- B. 按「总览 → 系统 → 部件」的认知顺序
- C. 按卡片数量从多到少

答案: B

解析: 先看整份图鉴怎么用，再看一套系统怎么分账，最后落到具体部件；顺序不是难度递增。
